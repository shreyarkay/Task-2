### EMS APP
This is the frontend application for the Employee Management System, built using Angular. It provides a user-friendly interface for users to manage employees, including registration, login, and CRUD operations. The word document gives a detailed process of creating the Angular app using Windows CLI.

**Features**
- User registration and login functionality
- Employee management (list, add, edit, delete) with form validations
- Secure routing with JWT-based authentication
- Responsive design for a better user experience

**Prerequisites**
- Node.js (version 14 or later)
- Angular CLI (version 12 or later)
  
**Components**
- User Registration
- User Login
- Employee Management(Employee-list.component, Employee-add.component, Employee-edit.component, Employee-delete.component)

  **Service**
- API Service
- JWT Service

  **Routing**
  - app-routing.module.ts: Routing configuration for the application

  **Security**
  - JWT-based authentication and authorization
  - Secure routing with protected routes for authenticated users
